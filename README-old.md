# Calculating the distance between points

# Description
This program calculates the distance between two points (x1, y1) and (x2, y2) on a 2D plane
using input values and a math library.

# How to Run
1. Open the program file
2. Run the program.
3. Enter the values for x1, y1, x2, and y2.
4. Check the distance calculated on the screen.

# Input Needed
- y2
- y1
- x1
- x2

# Examples
Enter x1: 1
Enter y1: 4
Enter x2: 5
Enter y2: 7

The distance between the two points is: 5.00
